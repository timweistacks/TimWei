# Tim Wei 報酬疊加實驗

公開的個人投資實驗紀錄：用實際帳本追蹤 Return Stacked 組合，並把過程放在網路上供查閱。

**網站：** https://timweistacks.github.io/TimWei/

---

## 這是什麼

這是一個**透明實測**，不是投顧或賣課網站。紀錄內容包含：

- 持倉、成交與 NAV 走勢  
- 貸款餘額與還款進度  
- 配置目標、再平衡與換匯紀錄  
- Return Stacking 概念說明與 Return Stacked ETF 百科（中／英可切換）

資料以公開 JSON 保存，並由靜態網站呈現；訪客看到的是與帳本一致的快照。
